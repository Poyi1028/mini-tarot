This file provides guidance to Codex (Codex.ai/code) when working with code in this repository.

## 回應語言

**一律使用繁體中文回應使用者**，無論使用者以何種語言提問。程式碼、檔案路徑、指令、識別字維持原文即可，但所有說明、解釋、對話內容與 commit message 都以繁體中文撰寫。

## Commands

Package manager is **pnpm** (see `pnpm-lock.yaml`).

```bash
pnpm install      # install deps
pnpm dev          # dev server at http://localhost:3000
pnpm start        # serve the production build
```

**請勿執行 `pnpm build`。** 它會寫入 `.next/` 產出，與 `pnpm dev` 使用的 `.next` 快取衝突，導致快取毀損、dev server 無法啟動。要驗證變更時，改用型別檢查：

```bash
npx tsc --noEmit  # 型別檢查（驗證的主要關卡，取代 pnpm build）
```

There is no separate lint/test script and no test suite. `tsc --noEmit` is the verification gate.

## Stack

Next.js 15 (App Router) · React 19 · TypeScript (strict mode) · Tailwind CSS v4 · framer-motion. Import alias `@/*` maps to the project root (`tsconfig.json`). The card model is a discriminated union (`MajorCard | MinorCard`) exported from `lib/tarot-cards.ts`; narrow on `arcana === 'minor'` to access `suit`.

## Architecture

**Single-screen, mobile-first PWA.** `app/page.tsx` renders `TarotApp` directly inside a centered, full-height (`100dvh`) column capped at `max-w-[480px]` — on phones it fills the viewport, on desktop it stays a portrait phone-width strip on an ink background. The wrapper applies `env(safe-area-inset-*)` padding (notch/home-bar), so screens' hardcoded `pt-[60px]/pt-[70px]` sit below the status bar. Keep new UI portrait and mobile-first. Installable via `app/manifest.ts` (generates `/manifest.webmanifest`) + `public/icon.svg`; PWA/viewport/theme-color/`viewport-fit=cover` metadata lives in `app/layout.tsx` (`metadata` + `viewport` exports). Service worker at `public/sw.js` handles offline caching: card images are cache-first, API calls bypass cache, everything else uses stale-while-revalidate.

**Screen flow is a client-side state machine.** `TarotApp.tsx` (`'use client'`) holds `screen` state and crossfades between six screens with framer-motion `AnimatePresence` (`mode="wait"`):

```
home → input → shuffle → spread ─(restart)→ home
  └──→ deck   牌庫 browser     (back → home)
```

`HomeScreen` contains the daily single-card draw, quote, and entry points for the main reading and deck; `InputScreen` collects the question; `ShuffleScreen` is the shuffle/cut interaction; `SpreadScreen` lays out the 3-card "聖三角" (past/present/future) and handles per-card flips, with a 50% reversal roll per card.

**Daily draw — `HomeScreen` + `lib/daily.ts`.** One card per *local* day (50% reversed): prepared when the home screen mounts but persisted to `localStorage` (`mini-tarot:daily-draw`) only when the user first flips it. Returning to home on the same day shows the card already face-up; the date key is local time, not UTC, so the card changes at local midnight.

**Deck library — `lib/deck-groups.ts` + `DeckScreen`.** Tabbed catalog (大牌 + four suits) whose detail view is `DeckCardDetail` (framed portrait, scrolling study page). The spread and daily screens use `CardDetailImmersive` (full-bleed, screen-blended art) instead — two intentionally different detail views; don't merge them.

**Shared building blocks.** Card faces: `CardFront` (artwork in a gold frame), `CardBack` (procedural gold-on-dark SVG), and `CardFlip` — the shared preserve-3d flip core used by both `SpreadScreen` and the home-screen daily draw; ambience layers stay in the callers. Shared controls live in `components/decor/`: `BackButton` (‹ top-left), `IconEntry` (icon + label corner entry), `TextAction` (quiet underline-link action), plus decorative SVG pieces (`OrnDivider`, `Constellation`, `Sunburst`, …). `components/SwipeBack.tsx` is an iOS-style edge swipe-back wrapper — built, but not yet wired into any screen. The motion language (easings, durations, tap springs) is centralized in `lib/motion.ts` (`EASE`, `DUR`, `TAP`, `SPRING_TAP`, …) — import these instead of hand-writing easing arrays.

**The shuffle animation is cosmetic.** `ShuffleScreen` animates `N_DECK` card backs purely for show; it does not pick the cards. The actual draw happens independently in `SpreadScreen` (`useMemo` shuffles `TAROT_CARDS` and slices 3). Changing the deck size means updating `N_DECK` in `ShuffleScreen` separately from the catalog.

**Card catalog — `lib/tarot-cards.ts`.** Exports `TAROT_CARDS = [...MAJOR_ARCANA, ...MINOR_ARCANA]` (78 total). Majors are a literal array; the 56 minors are generated by `buildSuit()` from `SUIT_META` + `SUIT_DATA` (per-card keywords/meanings only). Every card has: `num` (unique 0–77, used as the React key everywhere), `roman` (major = numeral, minor = suit symbol shown as the badge), `arcana`, `suit`, `cn`, `en`, `img`, `keywords[3]`, `meaning`. To add/edit minor cards, edit `SUIT_DATA`; the num/img/name are derived.

**Card rendering and the fixed aspect ratio.** Artwork lives in `public/cards/` (Rider-Waite PNGs, all **300×527**). `CardFront` renders `card.img` full-bleed inside a gold frame; `CardBack` is a procedural gold-on-dark SVG (the purple `CardBacks.png` is intentionally unused — it clashes with the theme). Cards render at per-screen hero sizes that all keep the 300×527 ratio exactly (no crop, no letterbox): **150×264** for the home-screen daily draw, **84×148** in `ShuffleScreen` (also the `CardFront`/`CardBack` defaults), and **124×218** in `SpreadScreen`. Each screen defines its card width/height constants and derives its tap-zone geometry from them — to resize a screen's cards, change both numbers and keep the ratio. The `CardBack` SVG `viewBox` + ornament coords are tuned to this ratio and only need touching if the artwork ratio itself changes.

## Theming conventions

The gold/ink/purple palette is defined in **two** places that must stay in sync:
- `app/globals.css` `@theme` block — Tailwind v4 design tokens (use as classes, e.g. `text-gold`, `bg-ink`, `font-display`). Named keyframe animations are also registered here (`animate-breath-glow`, etc.).
- `lib/constants.ts` — the same colors as JS constants (`GOLD`, `PARCHMENT`, …) for inline `style={{}}` props, which the SVG-heavy card components rely on.

Fonts: exactly two faces, loaded via `next/font` in `app/layout.tsx` — Cormorant Garamond for all Latin/digits and Noto Serif TC for all Chinese. The `--font-display` / `--font-serif` / `--font-cormorant` tokens all share one stack (Garamond first, Noto Serif TC fallback), so English always renders Garamond and Chinese always Noto Serif TC. UI copy is Traditional Chinese (`lang="zh-Hant"`).
